## 🚇 About

**TfL-Live** is a web project dedicated to London's iconic transport network, bringing a modern digital experience to the world of London travel.

Designed with a focus on accessibility, usability, and a clean interface, TfL-Live aims to make exploring London's transport information straightforward.

Whether you're a Londoner, a daily commuter, or simply fascinated by London's transport system, TfL-Live is a project built around the city that never stops moving.

## 🎨 Design Philosophy

TfL-Live takes inspiration from the distinctive visual language of London's public transport system.

- **Clarity first** — information should be easy to find.
- **Modern interface** — a clean, contemporary web experience.
- **London identity** — inspired by the city's recognisable transport colours.
- **Accessibility-minded** — an experience intended to be approachable across devices.
